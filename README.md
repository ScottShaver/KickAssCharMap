Libraries and Demos for using Charmap map files with the Kick Assembler on the C64.

Tools:

* Kick Assembler <- Java based assembler for C64 https://theweb.dk/KickAssembler/Main.html#frontpage
* Visual Studio Code 1.39.0 <- IDE https://code.visualstudio.com/download?_exp_download=fb315fc982
* KickAss (C64) v1.7.1 VS Code Extension <- helps with writing and assembling C64 assembly code  [https://theweb.dk/KickAssembler/Main.html#frontpage](https://marketplace.visualstudio.com/items?itemName=CaptainJiNX.kickass-c64)
* CharPad Free 2.86 <- char set and char map editing https://subchristsoftware.itch.io/charpad-c64-free/devlog/224389/charpad-free-edition-286
* C64 Debugger v0.64.58.6 <- powerful but confusing debugger https://sourceforge.net/projects/c64-debugger/

Folders:
* / <- for now this is where the demo programs are while I'm testing and fixing the library code
* /charmap <- data files for use in Charmap and the binary exports for the demo programs
* /kickasslibs <- library code for kick assembler that supports using Charmap files for games
